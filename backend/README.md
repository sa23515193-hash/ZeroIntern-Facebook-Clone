# FriendSpace API

Node.js + Express REST API with Socket.IO events.

```bash
npm install
npm run dev
```
Open `http://localhost:5000/api/health`.

This is an educational in-memory starter. Data resets on restart. Authentication, authorization, PostgreSQL persistence, Redis feed caching, rate limiting, moderation, and production-grade privacy enforcement must be implemented before production use. CORS is permissive for local development; restrict origins before deployment.
